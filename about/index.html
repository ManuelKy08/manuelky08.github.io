Tentang / kolofon

Satu meja untuk banyak eksperimen.

Project Desk adalah indeks publik proyek GitHub Pages Manuel Ky08. Isinya bukan portofolio yang dipoles untuk panggung, melainkan arsip kerja yang bisa dibuka satu per satu.

Manuel Ky08 adalah identitas publik di balik kumpulan proyek ini. Repositorinya bergerak di beberapa arah: alat keamanan, kalkulator, halaman bio, undangan digital, toko kecil, dan eksperimen antarmuka. Hub ini menyatukannya dalam satu format editorial supaya konteks dan statusnya terbaca.

Tidak semua proyek di sini adalah produk jadi. Sebagian adalah versi lama yang sengaja dibiarkan hidup; sebagian lagi latihan yang berhenti di titik yang cukup. Status dibuat jujur: aktif jika ada pembaruan dalam enam bulan terakhir, arsip ringan jika tidak. Tidak ada klaim bahwa proyek arsip sedang dirawat.

Apa yang bisa ditemukan

  • Alat dan referensi keamanan: kalkulator CVSS, dork engine, dan halaman pendukung riset.
  • Web personal: portofolio, bio-link, dan halaman identitas dalam beberapa iterasi.
  • Eksperimen visual: undangan digital, tema cyberpunk, dan halaman musiman.
  • Utilitas kecil: pencatatan saldo, ekspor CSV, dan antarmuka konversi.

Cara hub ini bekerja

Data proyek disimpan di data/projects.json. Skrip build.js membaca data itu dan menulis halaman statis: beranda, indeks, halaman per proyek, halaman tag, linimasa, devlog, tentang, sekarang, perangkat, statistik, halaman acak, sitemap, dan 404. Semua tautan internal memakai path relatif agar aman ketika dipasang di GitHub Pages.

Pencarian, filter tag, command palette, dan mode gelap dijalankan di browser dengan JavaScript vanilla. Tidak ada data pencarian yang dikirim ke server.
